# immo-playbook

Une formation complète à l'investissement immobilier en France, pour quelqu'un qui part de zéro. Les modules suivent l'ordre réel d'une opération : on prépare, on cherche, on visite, on négocie, on signe, on finance, on fait les travaux, on loue. Puis on approfondit : fiscalité, local commercial, marchand de biens, achat en Guadeloupe et à La Réunion.

> Retour d'expérience, pas un conseil personnalisé. Chaque règle fiscale ou bancaire porte sa date et sa source. Avant de décider : expert-comptable et notaire.

## Les 13 modules

| N° | Module | Vous saurez |
|---|---|---|
| 00 | [Préparer son premier investissement](00-preparer/) | Avant de regarder une annonce : savoir pourquoi on achète, combien on peut emprunter, et au nom de qui on signera. |
| 01 | [Rechercher un bien](01-rechercher/) | Construire son réseau et ses alertes pour voir les bonnes affaires avant les autres, puis les trier en cinq minutes. |
| 02 | [Visiter et chiffrer](02-visiter-et-chiffrer/) | Une visite sert à chiffrer : travaux, loyers, charges. On ressort avec un rendement net, pas une impression. |
| 03 | [Négocier et faire une offre](03-negocier-et-faire-une-offre/) | Le prix se gagne avant le compromis. Une offre écrite bien construite protège autant qu'elle négocie. |
| 04 | [Le compromis chez le notaire](04-le-compromis-chez-le-notaire/) | Première étape notariale : ce qu'on signe engage. Les clauses à exiger, les délais, le séquestre. |
| 05 | [Financer](05-financer/) | Parler banquier : comprendre comment le dossier est monté de l'autre côté du bureau, et le préparer pour qu'il passe en comité. |
| 06 | [L'acte authentique et la prise de possession](06-acte-et-prise-de-possession/) | Deuxième étape notariale : les fonds, la signature, les clés, et les quinze jours qui suivent. |
| 07 | [Les travaux](07-travaux/) | Les travaux font le rendement et la fiscalité. Les cadrer, les faire exécuter, les réceptionner. Option avancée : diviser. |
| 08 | [Mettre en location](08-mettre-en-location/) | Choisir le mode d'exploitation, trouver le bon locataire, sécuriser les loyers, gérer sans y passer ses soirées. |
| 09 | [Montage fiscal et structures](09-montage-fiscal-et-structures/) | Le module qui explique le choix fait au module 0 : nom propre, LMNP, SCI à l'IR ou à l'IS, SARL de famille, holding, transmission. Chaque règle porte sa date. |
| 10 | [Le local commercial](10-local-commercial/) | Un autre métier : le bail commercial, le locataire-entreprise, le rendement plus élevé et le risque de vacance. |
| 11 | [Marchand de biens](11-marchand-de-biens/) | Acheter pour revendre : un statut, une société, une TVA, des assurances, et des opérations dont on fait l'autopsie. |
| 12 | [Guadeloupe et La Réunion](12-guadeloupe-et-la-reunion/) | Le même droit, mais un foncier, des risques naturels, une assurance, des travaux et une gestion à distance qui changent le calcul. |

## Ce que contient chaque module

- `cours.md` : le cours complet, exporté en PDF dans `pdf/`.
- `memo.md` : l'essentiel sur une page, à imprimer.
- `outils/` : les calculateurs Excel et les modèles de documents.
- `exercice.md` : un cas pratique avec sa correction.
- `quiz.md` : dix questions pour vérifier qu'on a compris.

## Annexes

- [Lexique](annexes/lexique.md) : les 80 mots de l'immobilier expliqués simplement.
- [Sources](annexes/sources.md) : textes officiels, chaînes, livres.
- [Calculateurs](annexes/calculateurs/) : tous les Excel au même endroit.
