# 06. L'acte authentique et la prise de possession

Deuxième étape notariale : les fonds, la signature, les clés, et les quinze jours qui suivent.

## Plan du cours

1. L'offre de prêt : délai de réflexion, acceptation, déblocage des fonds
2. Les frais de notaire décomposés : droits, émoluments, débours ; ce qui est négociable
3. La lecture de l'acte : ce qu'il faut vérifier (surface, servitudes, état des lieux, compteurs, prorata de charges et taxe foncière)
4. Le jour J : chèque de banque ou virement, remise des clés, procès-verbal
5. Les quinze jours après : assurances (PNO, chantier), compteurs, syndic, impôts, changement d'adresse fiscale du bien
6. Si c'est une SCI : formalités, compte bancaire, première AG

## Action à réaliser avant le module suivant

Préparer la check-list du jour de signature et les cinq démarches des quinze jours suivants. Un module n'est terminé que quand son action l'est, pas quand le cours est lu.
