# Grille de comparaison de devis
Type : Modèle
Comparer trois devis sur un même lot de travaux, ligne par ligne, avant de signer.

> **Comment s'en servir**
> Remettez à chaque artisan le même descriptif écrit, puis reportez chaque devis dans la grille, ligne par ligne, en séparant ce qui est chiffré de ce qui manque. Cochez les vérifications de forme avant même de regarder les prix : un devis incomplet n'entre pas dans la comparaison. Retenez le devis dont vous comprenez chaque ligne, pas le moins cher.

## Décision

*Le choix se justifie par écrit, pour vous et pour la banque qui finance les travaux.*

- [ ] Les trois devis portent sur le même contenu, ou les écarts sont identifiés ligne par ligne
- [ ] L'écart entre le devis retenu et les autres est compris et expliqué
- [ ] Le devis retenu est dans la fourchette de prix au m² du mémo du module
- [ ] Le planning du devis retenu s'enchaîne avec les autres lots (feuille Planning de l'Excel)
- [ ] Le devis retenu est reporté dans la feuille Budget de l'Excel (colonne « Retenu »)
