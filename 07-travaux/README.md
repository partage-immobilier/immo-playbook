# 07. Les travaux

Les travaux font le rendement et la fiscalité. Les cadrer, les faire exécuter, les réceptionner. Option avancée : diviser.

## Plan du cours

1. Décider ce qu'on fait : rénovation légère, lourde, énergétique ; ce que le DPE impose
2. Les devis : ce qu'un bon devis contient, comparer, les prix au m² par poste
3. Choisir les artisans : assurances (décennale), références, acompte, planning
4. Électricité, plomberie, isolation : les trois postes qui coûtent et qui se voient à la location
5. Suivre le chantier : réunions, réserves, réception, retenue de garantie
6. Travaux et fiscalité : déductible, amortissable, TVA 5,5 %, MaPrimeRénov' (conditions 2026)
7. Option avancée : la division. Officieuse vs officielle, PLU, déclaration préalable ou permis, compteurs, copropriété, formulaires H2

## Action à réaliser avant le module suivant

Obtenir trois devis comparables sur un même lot de travaux et les mettre dans l'Excel de suivi. Un module n'est terminé que quand son action l'est, pas quand le cours est lu.
