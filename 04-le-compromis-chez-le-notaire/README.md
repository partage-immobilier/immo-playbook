# 04. Le compromis chez le notaire

Première étape notariale : ce qu'on signe engage. Les clauses à exiger, les délais, le séquestre.

## Plan du cours

1. Compromis ou promesse : différence et conséquences
2. Les conditions suspensives : prêt (montant, taux, durée), urbanisme, absence de servitude, vente d'un autre bien
3. La clause de substitution (acheter en SCI après avoir signé en nom propre)
4. Le séquestre : montant, où, quand ; refuser le versement direct au vendeur
5. Les délais : rétractation 10 jours, délai de réalisation, pénalités
6. Choisir son notaire : le sien, pas celui du vendeur ; frais partagés
7. Les pièces du dossier et le planning jusqu'à l'acte

## Action à réaliser avant le module suivant

Relire un compromis (le sien ou un exemple) et lister les clauses manquantes avec la check-list. Un module n'est terminé que quand son action l'est, pas quand le cours est lu.
