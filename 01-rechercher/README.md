# 01. Rechercher un bien

Construire son réseau et ses alertes pour voir les bonnes affaires avant les autres, puis les trier en cinq minutes.

## Plan du cours

1. Choisir son secteur : où investir et pourquoi (prix DVF, loyers, tension, vacance, projets de la ville) ; les outils qui complètent DVF (Pappers Immobilier, MeilleursAgents, Castorus)
2. Leboncoin, SeLoger, PAP et les agrégateurs (Moteur Immo, LyBox) : paramétrer les alertes, lire une annonce, repérer les signaux (prix, durée, photos, mots)
3. Le réseau : agents, notaires, artisans, syndics, commerçants ; comment on se présente et ce qu'on leur apporte
4. L'off-market : courrier, porte-à-porte, successions, divorces, ventes aux enchères
5. Trier en cinq minutes : le rendement brut depuis l'annonce, le prix au m² comparé au DVF
6. Tenir son tableau de suivi des annonces

## Action à réaliser avant le module suivant

Paramétrer ses alertes, contacter trois agents de son secteur, et remplir le tableau de suivi avec cinq annonces triées. Un module n'est terminé que quand son action l'est, pas quand le cours est lu.
