# 03. Négocier et faire une offre

Le prix se gagne avant le compromis. Une offre écrite bien construite protège autant qu'elle négocie.

## Plan du cours

1. Les leviers : diagnostics défavorables, DPE, travaux chiffrés, durée de l'annonce, double mandat, vacance, situation du vendeur
2. Combien proposer : le prix plafond calculé depuis le rendement cible, pas depuis le prix affiché
3. Négocier avec un agent, avec un particulier, avec une succession
4. L'offre d'achat écrite : contenu, durée de validité, condition suspensive de prêt, clause de substitution, sans séquestre
5. Ce qu'on ne révèle pas avant l'acceptation
6. Gérer un refus et une contre-proposition

## Action à réaliser avant le module suivant

Rédiger et envoyer une offre d'achat écrite sur un bien réel, même basse. Un module n'est terminé que quand son action l'est, pas quand le cours est lu.
